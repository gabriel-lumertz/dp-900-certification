# Introdução

A modelagem e a visualização de dados constituem o cerne das cargas de trabalho de business intelligence (BI) com suporte das soluções de análise de dados em grande escala. Basicamente, a visualização de dados capacita relatórios e tomada de decisões que ajudam a garantir o sucesso das organizações.

Neste módulo, você vai aprender os princípios fundamentais da modelagem analítica de dados e da visualização de dados usando o Microsoft Power BI como uma plataforma para explorar esses princípios em ação.
