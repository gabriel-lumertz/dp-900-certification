# Exercício: Explorar a análise de dados no Microsoft Fabric

Nesse exercício, você cria um data lakehouse do Microsoft Fabric e o usa para ingerir e analisar alguns dados.

O exercício foi projetado para familiarizar você com alguns dos principais elementos de uma solução em larga escala de análise de dados, não como um guia abrangente para executar análise avançada de dados com o Microsoft Fabric. O exercício levará cerca de 30 minutos para ser concluído.

> [!NOTE]
>
> Para concluir esse laboratório, você precisará de uma conta Microsoft Fabric ou, se ainda não tiver uma, inscreva-se para uma [avaliação gratuita](https://go.microsoft.com/fwlink/?LinkId=2182771).
>
> Acesse [Introdução ao Fabric](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para obter mais informações.

Inicie o exercício e siga as instruções.
