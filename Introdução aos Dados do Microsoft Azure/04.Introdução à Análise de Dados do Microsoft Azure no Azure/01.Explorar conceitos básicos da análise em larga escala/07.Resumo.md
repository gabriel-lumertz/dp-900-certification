# Resumo

O data warehousing de grande escala é uma carga de trabalho complexa que pode envolver muitas tecnologias diferentes. Este módulo ofereceu uma visão geral de alto nível dos principais recursos de uma solução moderna de data warehousing e explorou alguns dos serviços disponíveis no Azure que você pode usar para implementar uma dessas soluções.

Neste módulo, você aprendeu a:

- Identificar elementos comuns de uma solução em larga escala de data warehousing
- Principais características dos pipelines de ingestão de dados
- Identificar os tipos comuns de armazenamento de dados analíticos e os serviços do Azure relacionados
- Provisionar o Microsoft Fabric e usá-lo para ingerir, processar e consultar dados

## Próximas etapas
