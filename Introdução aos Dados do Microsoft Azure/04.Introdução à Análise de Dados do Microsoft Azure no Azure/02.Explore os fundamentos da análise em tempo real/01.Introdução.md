# Introdução

O aumento do uso da tecnologia por pessoas físicas, empresas e outras organizações, juntamente com a proliferação de dispositivos inteligentes e acesso à Internet, levou a um crescimento maciço no volume de dados que podem ser gerados, capturados e analisados. Grande parte desses dados pode ser processada em tempo real (ou pelo menos, *quase* em tempo real) como um *fluxo* perpétuo de dados, permitindo a criação de sistemas que revelam insights e tendências instantâneas ou tomam medidas responsivas imediatas aos eventos à medida que ocorrem.

> [!NOTE]
>
> Este módulo foi projetado para apresentar uma visão geral conceitual do processamento em tempo real e descrever os serviços do Azure que podem ser usados para criar soluções de análise em tempo real. Ele não se destina a ensinar detalhes de implementação para criar uma solução de processamento de fluxo.
