# Resumo

O processamento em tempo real é um elemento comum das soluções de análise de dados corporativos. O Microsoft Azure oferece uma variedade de serviços que você pode usar para implementar o processamento de fluxo e a análise em tempo real.

Neste módulo, você aprendeu a:

- Comparar o processamento em lotes e de fluxo
- Descrever elementos comuns de soluções de dados de streaming
- Descrever recursos e funcionalidades do Azure Stream Analytics
- Descrever recursos e funcionalidades da Inteligência em Tempo Real do Microsoft Fabric
- Descrever recursos e funcionalidades do Streaming Estruturado do Spark no Azure
